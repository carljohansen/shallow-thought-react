# Shallow Thought chess player in React/Typescript

To build and run the code, follow these steps:

1. Make sure you have Node.js and Npm installed.
2. Download the code to a local folder.
3. Start a command window in the code root folder.
4. Run `npm install`
5. Run `npm start`

Read the [article](https://carljohansen.wordpress.com/2024/10/03/shallow-thought-chess-player-in-react/) describing the code.

Read about the matches with [Chess.com bots](https://carljohansen.wordpress.com/2024/10/21/shallow-thought-versus-chess-com-bots/).
